# AnalyticalEngine 学习档案

这是参加 CTF 后留下的个人学习档案，不是题目官方仓库。原题为 Strellic 为 Hack The Box University CTF 2021 所作。

## 防御复盘

| 关注点 | 复盘时值得记录的问题 |
| --- | --- |
| 输入与输出 | 不可信输入经过哪些边界？不同输出位置是否做了对应的编码？ |
| 浏览器防护 | 安全策略能减轻哪些风险？哪些风险仍应在应用层修复？ |
| 回归验证 | 修复后哪些正常输入仍应可用？哪些异常输入应被拒绝或安全显示？ |

本页仅说明出处和防御学习目标，不提供操作步骤。保留档案是为了方便复盘，不代表允许对其他系统进行测试。
